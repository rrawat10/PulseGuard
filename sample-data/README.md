# ECG sample

`ptbxl-00001-lead-II.csv` contains 5,000 Lead II samples at 500 Hz from record 00001 in [PTB-XL v1.0.3](https://physionet.org/content/ptb-xl/1.0.3/). Values are in millivolts. Source DOI: 10.13026/kfzx-aw45. PTB-XL is licensed under CC BY 4.0.

The file can be uploaded on the Live pulse page to exercise the actual inference path. A model score is not a diagnosis.
